# Marketing Campaign Performance Analysis

**Dataset:** 6,600 rows x 10 columns, 6,500 after removing 100 duplicates.

**Key results:** 6,500 leads, 1,259 conversions, conversion rate 19.37%, total ad spend 1,302,295.92, cost per conversion 1,034.39. Welch t-test on ad spend, converted vs not: p = 0.28 (not significant).

**Case study:** `analysis.html` (problem, data, method, findings, recommendation, next steps).

**Files**
- `analysis.ipynb`: the Jupyter notebook. It reads `marketing_campaign_data.csv`; the site's Dataset link downloads `data.csv` under that name.
- `analysis.html`: the case study page
- `data.csv`: the dataset

**Stack:** Python, Pandas, NumPy, Matplotlib, Seaborn, SciPy, Jupyter
